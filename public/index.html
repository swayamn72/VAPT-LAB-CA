Source Code Vulnerability & Remediation Analysis

Finding 1: SQL Injection (CWE-89)

❌ Vulnerable Implementation (routes/users.js)
// Raw string concatenation allows injection
const rawSql = `SELECT id, username, email, role, balance 
  FROM users 
  WHERE username LIKE '%${query}%' OR email = '${query}'`;

const results = db.prepare(rawSql).all();
✓ Secure Remediation (Parameterized Query)
// Parameterized query with bound parameters
const sql = `SELECT id, username, email, role, balance 
  FROM users 
  WHERE username LIKE ? OR email = ?`;

const results = db.prepare(sql).all(`%${query}%`, query);

Finding 2: Broken Object-Level Authorization (IDOR - CWE-639)

❌ Vulnerable Implementation (routes/statements.js)
// Direct fetch solely by URL parameter ID without ownership check
const statement = db.prepare(`
  SELECT * FROM statements WHERE id = ?
`).get(req.params.id);
✓ Secure Remediation (Enforced Session Ownership)
// Enforces user_id ownership binding from validated session
const statement = currentUser.role === 'admin' 
  ? db.prepare('SELECT * FROM statements WHERE id = ?').get(statementId)
  : db.prepare('SELECT * FROM statements WHERE id = ? AND user_id = ?').get(statementId, currentUser.id);

if (!statement) return res.status(403).json({ error: 'Access Denied' });

Finding 3: Cross-Site Scripting (XSS - CWE-79)

❌ Vulnerable Implementation (routes/feedback.js)
// Raw unescaped storage & direct innerHTML rendering
db.prepare('INSERT INTO feedback (author, message) VALUES (?, ?)').run(author, message);
// Browser executes: container.innerHTML = feedback.message;
✓ Secure Remediation (HTML Encoding & CSP)
// Neutralize dangerous meta-characters before rendering
const safeMessage = message
  .replace(/&/g, '&').replace(//g, '>');

res.setHeader('Content-Security-Policy', "default-src 'self'; script-src 'self';");
// Browser renders safely via textContent

Finding 4: Insecure Credential Storage (CWE-256) & Brute Force

❌ Vulnerable Implementation (routes/auth.js)
// Weak MD5 verification, no rate-limiting, and leaks full DB row
const inputMd5 = crypto.createHash('md5').update(password).digest('hex');
if (user.password_md5 === inputMd5) {
  return res.json({ user }); // Leaks password hashes and National ID
}
✓ Secure Remediation (Bcrypt & Lockout Protection)
// Adaptive salted bcrypt hash verification & account lockout
if (!bcrypt.compareSync(password, user.password_bcrypt)) {
  attemptsTracker.registerFailure(clientIp);
  return res.status(401).json({ error: 'Invalid credentials' });
}
// Whitelisted safe projection:
const { id, username, email, role } = user;
return res.json({ user: { id, username, email, role } });

Finding 5: Information Disclosure & Debug Misconfiguration (CWE-200)

❌ Vulnerable Implementation (routes/system.js)
// Debug endpoint exposes environment and runtime keys
router.get('/debug', (req, res) => {
  res.json({ env: process.env, dbKeys: internalConfig });
});
✓ Secure Remediation (Disabled In Prod & Generic Errors)
// Diagnostic routes disabled; exceptions return opaque incident IDs
router.get('/debug', (req, res) => res.status(404).json({ error: 'Not Found' }));

// Centralized error handler:
res.status(500).json({ error: 'Internal Error', incidentId: 'INC-9912' });

Executive Summary Excerpt

During October 2026, our security team performed an authorized Vulnerability Assessment and Penetration Testing (VAPT) engagement on the SecureBank Portal web application within an isolated laboratory environment (127.0.0.1:3000). The assessment identified five (5) critical security vulnerabilities spanning OWASP Top 10 categories, including SQL Injection, Insecure Direct Object References, Stored/Reflected XSS, Broken Authentication, and Security Misconfigurations.

All vulnerabilities were successfully reproduced in a non-destructive manner and subsequently remediated using industry-standard secure coding patterns (parameterized queries, session-tied authorization matrices, HTML context encoding, salted bcrypt hashing, and defense-in-depth security headers). Post-remediation verification confirmed 100% mitigation of identified attack vectors.
